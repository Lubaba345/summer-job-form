# Summer Jobs Form

A static HTML/CSS recreation of a Canada Summer Jobs Part A - Employer Information form.

## Project Files
summer-job-form/
├── summer_job_form.html
├── summer_job_form.css
├── summer_job_submitted.html
├── README.md
└── .gitignore
```

## Features

- Multi-section employer information form
- Required HTML form validation
- Radio buttons, checkboxes, text fields, email, URL and number inputs
- Funding and amount-owing tables
- Health and safety section
- Work environment section
- Reset and Submit buttons
- Confirmation page after submission
- Responsive viewport metadata
- External CSS stylesheet

## Run Locally

No installation needed.
 click summer_job_form.html

## Notes

This is a static front-end demonstration. Submitting the form navigates to the included confirmation page; it does not send data to a server or database.
live URL: https://karim13.myweb.cs.uwindsor.ca/Summerjobform/summer_job_form.html
